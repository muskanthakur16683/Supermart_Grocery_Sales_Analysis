# Supermart Grocery Sales Analysis

## Project Overview
This project analyzes grocery sales data using Microsoft Excel 2021. The goal is to understand sales performance, profit trends, and regional business insights through an interactive dashboard.

## Tools Used
- Microsoft Excel 2021
- Pivot Tables
- Pivot Charts
- Slicers
- Interactive Dashboard

## Project Objectives
- Analyze total sales and total profit.
- Identify top-performing product categories and sub-categories.
- Compare sales performance across regions.
- Analyze monthly and yearly sales trends.
- Track key performance indicators (KPIs).

## Key Insights
- West region recorded the highest sales.
- Eggs, Meat & Fish was the highest-selling category.
- Health Drinks was the leading sub-category by sales.
- November recorded the highest monthly sales.
- Snacks generated the highest category-level profit.
